                                   🧠📊 Panic Attack Analysis & Power BI Dashboard 🧠📊

An interactive **Power BI dashboard** designed to analyze panic attack frequency, duration, symptoms, triggers, lifestyle factors, and panic severity.

## 📌 Project Overview

This project analyzes panic attack data using **Power BI, DAX, SQL, and data visualization techniques**.

The dashboard provides insights into patient characteristics, panic attack symptoms, triggering factors, lifestyle patterns, and panic scores.

The analysis covers factors such as **age, gender, panic attack frequency, attack duration, trigger reasons, medical history, caffeine intake, exercise frequency, sleep hours, alcohol consumption, smoking, medication, and therapy**.

## 🎯 Project Objectives

* Analyze panic attack patterns across different age groups and genders
* Study the frequency and duration of panic attacks
* Identify common symptoms associated with panic attacks
* Analyze different panic attack trigger reasons
* Examine relationships between lifestyle factors and panic-related measures
* Compare panic severity using panic score categories
* Build an interactive Power BI dashboard for data-driven analysis

## 📊 Dashboard Features

### 🩺 Symptom Analysis

The dashboard analyzes the number of patients experiencing:

* Dizziness
* Trembling
* Sweating
* Shortness of Breath
* Chest Pain

The report shows, for example, **620 patients with dizziness** and **590 patients with trembling** in the displayed analysis.

### 🎯 Panic Score & Demographic Analysis

Interactive filters allow analysis by:

* Panic Score — High, Medium, Low
* Gender — Female, Male, Non-binary
* Trigger Reason — Caffeine, Phobia, PTSD
* Medical History — Anxiety, Depression, None

### ☕ Lifestyle Analysis

The dashboard analyzes:

* Drinks per week
* Sleep hours
* Panic attack duration

These visuals help compare lifestyle patterns with panic-related measures.

### 📈 Age Group Analysis

The dashboard compares **Average Sleep Hours, Average Panic Score, and Average Panic Attack Frequency** across age groups and trigger reasons.

## 💡 Key Insights

* Symptoms such as dizziness, trembling, sweating, shortness of breath, and chest pain can be analyzed separately across the dataset.
* Panic severity can be segmented into **High, Medium, and Low** categories.
* Trigger reasons include **Caffeine, Phobia, and PTSD** in the dashboard.
* Sleep hours, drinks per week, and attack duration provide additional dimensions for understanding panic-related patterns.
* Age-group analysis enables comparison of sleep, panic score, and panic attack frequency.
